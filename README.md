# To-Do List (Lista de Tarefas)

Este é o meu primeiro projeto focado em lógica de programação para o estágio. 

### 🚀 Tecnologias Utilizadas:
* HTML5
* CSS3 (Animações e Flexbox)
* JavaScript Vanilla (Manipulação de DOM)

### 🧠 O que eu aprendi:
Neste projeto, foquei em aprender como o JavaScript interage com o HTML para criar elementos dinamicamente. Também implementei o uso de **LocalStorage** para que as tarefas não sumam quando a página é atualizada.

### 🛠️ Funcionalidades:
- Adicionar tarefas (via botão ou tecla Enter).
- Editar tarefas existentes.
- Excluir tarefas.
- Persistência de dados local.
